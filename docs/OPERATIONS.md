# Эксплуатация ColaBike

Runbook разделён по задачам:

- [Развёртывание](operations/deployment.md): конфигурация, миграции, домен, TLS и первый администратор.
- [CI/CD](operations/ci-cd.md): выбор staging/production, точный SHA и обслуживание wrappers.
- [Backup и restore](operations/backup-restore.md): согласованный снимок, off-host копия и отдельная пустая цель.
- [Мониторинг и диагностика](operations/monitoring.md): health, версии, файлы и сетевые отказы.

Путь сохранён для существующих ссылок. Здесь больше нет устаревшего описания модулей и одноразовых указаний «перед merge этого PR».
