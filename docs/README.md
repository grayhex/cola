Новому разработчику: **[первый запуск](development/getting-started.md) → [архитектура](architecture/overview.md) → [правила разработки](development/principles.md) → [нужный модуль](#модули-приложения)**. ## Статус и совместимость

Это описание реализованного приложения, не список обещаний. OAuth-вход, Garmin/Strava-синхронизация, личные сообщения и автоматический откат не считаются готовыми только потому, что обсуждались или для них существует иконка. Реальную доступность внешнего источника нельзя вывести из успешного fixture-теста.

Старые верхнеуровневые Markdown-файлы оставлены как **указатели**, чтобы ссылки из прежних PR и README не ломались. Они не содержат вторую версию инструкций. Устаревшие протоколы ручной приёмки, разовые сетевые наблюдения и планы дизайна не являются текущими требованиями; их история доступна в Git.

Порядок глав для будущей сборки в единый документ задан в [book.json](book.json). Секреты, реальные GPX и пользовательские выгрузки в документацию не включаются.
