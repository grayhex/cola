# Единый набор иконок ColaBike

## Импорт готового ZIP

Админка → Оформление → **Единый набор ColaBike · 64 иконки**.

1. Выберите `colabike-unified-icons.zip` целиком: распаковывать и переименовывать файлы не нужно.
2. В предпросмотре проверьте пары «текущая → новая», отметьте нужные слоты и выберите режим:
   «Заменить выбранные» или «Только заполнить пустые».
3. Нажмите «Импортировать … иконок в настройки», затем штатное **«Сохранить настройки»**.

Предпросмотр ничего не записывает. Подтверждение создаёт медиа-ресурсы и изменяет
локальный черновик настроек. Публикация выполняется существующим версионированным
сохранением: посторонние несохранённые изменения не теряются, а конфликт с другим
администратором обрабатывается прежним механизмом. Не закрывайте страницу до сохранения.

Все 64 слота перечислены по группам. У каждого есть просмотр на прозрачной
подложке, выбор ранее загруженного ресурса, отдельная загрузка и возврат к
встроенному значку. Поиск работает по точному имени и русскому назначению.

## Формат

Используются PNG-мастера из `png/<name>.png`; допускается внешняя папка архива.
Отдельные известные PNG/WebP с теми же именами также распознаются. `png/` имеет
приоритет перед копией в корне; два равноприоритетных мастера одного слота — ошибка,
а не случайный выбор. Частичный набор разрешён: отсутствующие слоты не очищаются.

SVG, `png-24/`, `png-32/`, `png-40/`, `png-256/`, sprite sheets, preview,
README, manifest и исходники из полного комплекта пропускаются. Они не нужны
для публикации PNG-мастеров и никогда не исполняются. SVG-загрузка намеренно
не включена: в комплекте уже есть растровый мастер каждого знака.

Отдельная иконка: статический квадратный PNG или WebP, 16–512 px, до 2 МБ;
рекомендованный мастер — 64×64. Сервер проверяет сигнатуру и декодирует картинку.
Хранение — **lossless WebP** в существующем `site_assets`, без изменения размера,
с сохранением прозрачности. Фото-конвертер с потерями не используется. Маленький
предпросмотр создаётся отдельно, nearest-neighbour; он не заменяет мастер.

Баннеры, общий фон, логотип, favicon, фотографии, награды конкретных пользователей
и графика отдельных компонентов этим импортом не заменяются.

## Интеграция

`lib/icon-pack.js` — общий реестр всех 64 семантических имён, групп, назначений,
встроенных альтернатив и совместимости со старыми слотами.

Назначения хранятся в существующей карте `settings.uiIcons`, например:

```js
{ uiIcons: { journal: "asset-uuid", saved: "asset-uuid", saved_active: "asset-uuid" } }
```

Приоритет: явное семантическое назначение → прежний специальный слот → прежняя
Lucide-настройка → встроенный значок. `null` в семантическом слоте означает
явный возврат к встроенному варианту. Импортированные слоты заменяйте в новом
каталоге, а не в старых настройках Lucide/навигации.

`withIconPack` связывает новые назначения со старой навигацией, поиском, лайками
и категориями **только для отображения**, не дублируя их в сохранённых полях.
`SiteIcon` подключает семантический значок в любом клиентском компоненте:

```jsx
<SiteIcon name="search_experience" size={24} aria-hidden="true" />
<SiteIcon name={saved ? "saved_active" : "saved"} size={24} />
```

Общие UI-примитивы поддерживают совместимые назначения автоматически. Журнал
использует отдельные состояния закладки, типы записей и статус решения. Для
нового действия выбирайте семантическое имя, не перегружайте один Lucide-слот
несколькими разными смыслами. Альтернативные и пока не используемые слоты
(например, `bookmark_alt`, `compare`) доступны для загрузки и последующего
применения через `SiteIcon`; импорт не создаёт новые продуктовые функции.

Для типов велосипедов зарегистрированы все семь иконок; существующие категории
сопоставляются по идентификатору/названию. Схема каталога и данные велосипедов не
меняются. У иконки без текста кнопка сохраняет своё доступное название.

## Безопасность и лимиты

`POST /api/admin/icon-pack?action=preview|stage|single`: только администратор,
проверка Origin и ограничение частоты до чтения тела запроса. ZIP — до 10 МБ,
1024 записей, 32 МБ суммарного заявленного размера после распаковки; выбранный
файл — до 2 МБ. Поддерживаются обычные STORE/DEFLATE, без ZIP64, шифрования,
многотомных архивов, ссылок и небезопасных путей. Проверяются локальные заголовки,
перекрытия, CRC и фактический размер. Inflate ограничен `maxOutputLength`.

Пути архива не используются для записи на диск. Ресурсы получают новые UUID;
частичная ошибка записи/транзакции вызывает очистку подготовленных файлов.
Существующие ресурсы не удаляются автоматически. При конфликте настроек или
отменённом сохранении подготовленные ресурсы остаются в обычном разделе Медиа.
Действие подготовки записывается в аудит. Защита используемых ресурсов от удаления
сохраняется: все новые ссылки находятся в `uiIcons`, учитываемой `siteAssetIds`.

## Проверки

```sh
node --test tests/icon-pack.test.js tests/icon-pack-images.test.js
COLABIKE_ICON_ARCHIVE=/path/to/colabike-unified-icons.zip node --test tests/icon-pack.test.js
```

Ручная проверка: полный/частичный импорт; режим заполнения пустых; замена одной
иконки; сохранение и перезагрузка страницы; навигация, поиск, новые/популярные,
закладка в обоих состояниях, типы записей; конфликт версий; отсутствие прав;
повреждённый ZIP; отсутствие изменений баннеров и фотографий.
