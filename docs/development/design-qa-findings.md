## Detector: данные и решения

CLI **4.5.2**, engine **0.1.14**, skill commit `d631a8827f99414d2b6daba4ef08b7f8701751d7`.
Source scan `app/`: exit **2**, **68** находок в **27** файлах — **5 primary**,
**63 advisory**. `source-scan.json` содержит точные файлы/строки.

| Группа        |  Количество | Контекст / решение                                                                                                                                                 |
| ------------- | ----------: | ------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| font-size     | 55 advisory | Literal 13px, rem чата и fluid endpoints маркетинга. Проверены роли и rendered samples; глобальная замена размеров не обоснована. Не расширять шкалу ради scanner. |
| radius        |  6 advisory | Малые декоративные радиусы и компоненты существующего UI. Подтверждённого дефекта геометрии нет.                                                                   |
| color         |  2 advisory | Start/finish markers карты; нет основания менять смысл цветов. Контраст реальной карты остаётся адресной проверкой.                                                |
| side-tab      |   4 primary | Непрочитанные уведомления («Новое»), тип строки и границы цитат — семантические сигналы, не случайное украшение. Сохранены.                                        |
| gradient-text |   1 primary | Принятый Storage reference маркетингового /about. Не менять визуальный язык по предпочтению detector.                                                              |

Rendered CLI реально открыл guest `/`, `/about`, `/bikes`, `/rides`,
`/experience` при **390×844** и **1440×900**. У /about exit **2**:
**25** mobile (22 primary/3 advisory), **28** desktop (25/3); остальные восемь
сканов exit **0**, без находок. Ноль не означает отсутствие UX-дефектов.

На /about: 5 contrast flags статистики — неверная интерпретация detector
нижней серой полосы под верхней белой заливкой (реальный текст ~4.83:1);
15/10 occlusion flags — декоративные aria-hidden glyphs под полезным текстом;
8 desktop icon stacks, gradient word, hatching и русская пунктуация —
существующие решения. Один contrast advisory иллюстрации подтверждён Q408-06.
Raw counts сохраняются; ignore rules/config не добавлены.

Первый rendered batch завершился exit **1** из-за Chromium crashpad/sandbox,
его `[]` — ошибки. Повтор после writable `XDG_CONFIG_HOME` и upstream
container mode `CI=1` выполнился. CSP/TLS/проверки целостности не отключались.
Все попытки live `/detect.js` overlay блокированы nonce-based `style-src`;
видимый overlay не подтверждён. Использованы CLI JSON, screenshots и DOM.
Временный live-server остановлен, приложение осталось доступно.

## Проверка исправлений Q408-01/02

Общий owner/form контекст держит только данные текущего документа;
подтверждённая Отмена, успех и смена владельца очищают их. Pending task
сохраняет identity, не перенаправляет из уже закрытого редактора и блокирует
повторную отправку до завершения. Файл после частично неудачной загрузки
остаётся доступен для повтора без второго создания записи.

Локально: **817 unit passed**; production build, lint, production/test types,
format. Chromium **22 passed** и mobile WebKit **22 passed**, отдельно с новыми
изолированными БД; 11 новых контрактных сценариев + существующие публикация,
иллюстрации/таблицы, privacy, каталог рынка и #399. Desktop 1440 и mobile 393,
light/dark для восстановления/очистки форм. Budget suite: **3 passed** в
Chromium, **3 expected skips** в WebKit; лимиты eager JS не менялись.

Source после исправления: **68**, **5 primary / 63 advisory**, как baseline;
новых styling findings нет. Выход detector **2**, правила не подавлены.
Скриншоты `content-drafts-*/journal|article|market-393|1440-light|dark-restored.png`
и pending доступны в browser-review artifacts соответствующего CI.

При совместном запуске старых publication tests сразу в двух projects в одной
БД обнаружились совпадающие фиксированные fixture titles. Повтор выполнен
отдельно на каждый project, как настроено CI, с новой БД каждый раз;
production code и утверждения старых тестов не менялись.

Owner scope дополнительно проверен: сбрасываются maps и конкретные редакторы,
без remount всего сайта/мастера/страницы входа. Сохранённая ревизия очищается
до native перехода, поэтому успешный save не вызывает ложный beforeunload;
ошибка последующего перехода возвращает recovery-контракт. Дополнительные
сценарии: Chromium **24 passed**, WebKit **23 passed / 1 expected skip**;
точечная регрессия восстановления пароля и входа на странице велосипеда —
Chromium **4 passed**, WebKit **4 passed**.
