# Интерфейс и дизайн-система

[Оглавление](../README.md)

## Принципы

Функциональный интерфейс плотный, плоский, с ясной иерархией и сдержанным акцентом. Брендовая графика используется в шапке, иллюстрациях и наградах, а не превращает каждую кнопку в большую карточку. Плотность не означает нечитабельный текст, скрытые действия или горизонтальное переполнение.

На витрине главный объект — фотография велосипеда. Публичная карточка содержит название и максимум один факт (вес), затем владельца, лайк и комментарии. MicroMetrics и ссылка на похожие сборки остаются в варианте владельца и на странице велосипеда. Профили, поиск и подписки используют тот же компонент. Неизвестные счётчики не заменяются нулями. Страница рекордов — осознанное исключение: крупная иллюстрация награды, название велосипеда-ссылка и вторичное значение, **без фото победителя**.

## Пресет «Пиксельный велоклуб»

В админке: **Дизайн → Оформление → Применить «Пиксельный велоклуб» → Сохранить**. Кнопка меняет только черновик оформления; автоматической миграции старых настроек нет. Пресет выбирает светлую тему, три колонки, радиус 4 px и прозрачность фоновой картинки 0. Asset ID, пользовательский заголовок витрины, copy, назначения иконок и загруженные файлы сохраняются. Персональные тема, основной шрифт, акцент и число колонок по-прежнему имеют приоритет. Другие темы не получают светлую палитру пресета.

| Роль | Значение |
| --- | --- |
| `--wash` / фон | `#EEF1F4` |
| `--paper` / поверхность | `#FFFFFF` |
| `--ink` / основной текст | `#1E2830` |
| `--muted` / вторичный текст | `#52616B` |
| `--accent` / акцент | `#244CBA` |
| `--control-border` / значимая граница | `#7E8C97` |
| `--line` / декоративный разделитель | `#D7DEE4` |

`--accent-ink` и `--button-ink` выбирают чёрный или белый текст по относительной яркости сохранённого акцента. Фокус имеет дополнительную контрастную границу; выбранный лайк обозначается заполнением и подчёркиванием, а не только цветом.

PT Sans 400/700 — основной текст (16/24), навигация (14/20), название велосипеда (17/22 bold), автор и факты (13/18). Unbounded 600 — только короткий заголовок витрины: 40–48 px desktop, 26–30 px mobile. Роли независимы: `font` и `displayFont`. Файлы с кириллицей находятся в `public/fonts`, лицензии OFL рядом; внешнего font `@import` нет. Старый каталог шрифтов сохранён.

## CSS и движение

Используйте семантические переменные `--ink`, `--muted`, `--line`, `--paper`, `--wash`, `--accent`, согласованный ритм отступов и ограниченные радиусы. Реальные токены смотрите в [product-ui.css](../../app/product-ui.css), не создавайте параллельную тему.

Геометрией шапки и панорамы владеет `global-header.module.css`, карточки — `bike-card.module.css`, сетки — `bike-grid.module.css`, заголовка/действий витрины — `garage.module.css`. Соответствующие старые правила удалены из глобальных файлов. Не возвращайте `.site-root .bike-card` и параллельные переопределения. Общий CSS хранит reset, токены и общие controls. Слои: header 2, popover 3; модальные диалоги используют native top layer.

На витрине один постановочный переход: весь готовый набор меняет прозрачность за 160 ms. Карточки не размонтируются ради анимации; фото не масштабируются, панорама неподвижна. `prefers-reduced-motion` отключает этот переход. Начальная загрузка использует статические заполнители с зарезервированной геометрией. При фильтрации остаются старые карточки и один скрытый `status`.

`/me` и публичные данные запрашиваются параллельно. Номер запроса защищает и успешные, и ошибочные результаты от устаревания, включая интервал debounce. Sort/category/q/page синхронизируются с URL через Next-compatible native history; основные переходы — `Link`. При возврате через history прокрутка восстанавливается после загрузки списка; сохраняются только координаты, не данные о правах. Реакция имеет отдельную последовательную очередь для каждого велосипеда, мгновенное локальное состояние и откат к последнему подтверждённому ответу. Общий `busy` остаётся для редактирования, не для лайков.

## Верхняя графика

На главной компактная навигация и панорама идут от края до края, без внешних радиусов, со стыком 6 px. Навигация занимает собственную спокойную поверхность. На внутренних страницах остаётся только шапка. Высота mobile около 64 px, основные действия от 44×44 px; ниже 1100 px используется мобильное меню с той же структурой и правами. Название раздела — прямая ссылка, соседний шеврон — отдельная кнопка. Escape закрывает меню и возвращает фокус.

Существующие слоты `logoId` и `garageImageId`, импорт архивом и точечная замена сохранены. **Дизайн → Оформление → Брендинг** содержит desktop 1440 и mobile 390: это реальные компоненты, масштабированные после раскладки, с теми же container queries.

| Ресурс | Контракт |
| --- | --- |
| Старый logo-баннер 2172×724 | `headerArtworkFit=padded-strip`: центральная горизонтальная полоса, логотип в первых ~804 px исходника. Этот режим рассчитан на существующий ресурс. |
| Новый логотип без пустых полей | 800×160 px, значимое содержимое внутри 16 px от краёв; режим `contain`, показ целиком. |
| Панорама | Рекомендуется 2400×270 px; лица/надписи в центральной зоне 2400×200 px. Desktop-область 9:1, кадрирование по центру. |
| Mobile fallback | Область с отношением 2400:487, `contain`: показываем весь исходник, возможны поля для другой пропорции. Не растягиваем графику; отдельный мобильный ресурс не требуется. |

Для исходной панорамы 2400×487 desktop обрезает края по вертикали, mobile показывает всю сцену. Предпросмотр позволяет оценить замену до сохранения. При ошибке логотип заменяется названием, панорама сохраняет зарезервированное место; отсутствующий слот не создаёт пустой блок. Фото велосипедов всегда `contain`, без `pixelated`.

## Адаптивность и приёмка

Проверьте длинные названия, отсутствующее фото, большие прозрачные картинки, ошибку загрузки, обе темы и фон tile/cover. Проверьте мышь, клавиатуру, Escape, возврат фокуса и touch. Иконка без текста требует доступного имени кнопки/ссылки. Увеличенная награда не должна менять hit target соседней ссылки.

Оболочка витрины до 1536 px, поля 24 px desktop / 12 px mobile, gap 16 px. Выбранные 3/4/5 колонок — верхний предел; минимальная карточка 280 px, до 600 px одна колонка. Текст переносится без фиксированной высоты. Локальная сетка рекордов имеет собственные breakpoint и группы. Приёмочная матрица: 320, 390, 768, 1024, 1440, 1920; 844×390; текст 200%; reduced motion; долгий/ошибочный ответ и отсутствие графики.
