## Выбор места изменения

| Симптом                                    | Где исправлять                                |
| ------------------------------------------ | --------------------------------------------- |
| Нужная товарная страница не найдена        | Discovery адаптера или retailer search        |
| Найден соседний год/trim                   | Matching и metadata evidence                  |
| Страница не скачивается                    | HTTP/DNS/redirect, не CSS-селектор            |
| HTML есть, но извлечено мало деталей       | Extraction, site profile, label normalization |
| Правильный preview портится при сохранении | App wizard/factory import, не Resolver core   |

Основные файлы перечислены в [архитектуре](architecture.md). Не вносите product-specific URL или готовую комплектацию как исключение для одного велосипеда.

## Новый производитель

Изучите публичные страницы/архивы и сохраните минимальный fixture с происхождением. Реализуйте `BikeManufacturerAdapter` либо расширьте `CatalogueAdapter` в [adapters/base.ts](../../services/bike-resolver/src/adapters/base.ts): discovery, fetch и parse имеют разные роли. Домены официального источника задаются явно; используйте общий safe HTTP client.

Зарегистрируйте адаптер в [adapters/index.ts](../../services/bike-resolver/src/adapters/index.ts), согласуйте aliases, defaults и ограничения в settings. Проверьте совместимость уже сохранённых settings: новый флаг нельзя считать активным только потому, что он появился в исходном default. При необходимости добавляется собственная миграция Resolver.

Подтверждённый год/trim должен происходить из страницы. Unknown year не должен автоматически совпадать с запросом. Ключ адаптера в `adapterSupport` с непустым текстом выключает адаптер по умолчанию; пометки для включённого адаптера лежат в `adapterNotes` и показываются в `/v1/brands`. Ключи адаптеров, появившихся после первого релиза, читаются с default: сохранённые ранее settings загружаются без них. Для явного выбора кандидата есть отдельный путь, но он тоже сохраняет неопределённость. Ненадёжный адаптер лучше оставить выключенным и описать ограничение; актуальные флаги смотрите в `/v1/brands`, не в старой таблице «поддерживаемые бренды».

Состояние на 2026-10-07: страницы получены живыми запросами через safe HTTP-клиент, фикстуры лежат в `tests/fixtures/manufacturers/` с манифестом (SHA-256, правило сокращения, происхождение, ожидаемый результат). **ROSE.** Страница велосипеда отличается от детали блоками велосипеда (`data-test="bike-…"`); без них `parse` отвечает `not_complete_bike` (ремённая вставка «Black Lava», чехол для тросов Black Lava / Backroad AL — это детали с именем велосипеда в адресе). Названия `Black Lava 2`, `BLACK LAVA 2`, `BlackLava 2` — одна модель; `MidStep` и другие варианты рамы — отдельные страницы, не склеиваются; `Unsupported` — часть названия, не ошибка `unsupported_brand`. Строка «Pedals are not included in the scope of delivery» не становится педалями. Контрольные запросы честно не подтверждаются точным годом:

- `rose backroad unsupported 2025` — живая страница одна, `rose-backroad-unsupported-2725748` (в sitemap есть и `…-165481`, она отвечает 404). Страницы 2025 года нет: в Common Crawl CC-MAIN-2025-38 у rosebikes.com только robots.txt, адреса этой и соседних страниц в выборках 2022–2025 не найдены, web.archive.org недоступен из среды разработки. Результат — вариант без года; год указывает владелец. Это не «точный контрольный тест 2025».
- `rose black lava 2 2023` — три живые страницы Black Lava 2 (`160438` в текущем каталоге, `2706827` и `2723490` только в sitemap) и их MidStep. Адреса 2023 года (`2702485`, `2702487`) отвечают 404. Сохранена запись Common Crawl страницы прежнего магазина от 2023-10-04 (19 компонентов): она доказывает, что парсер читает такие страницы, и датирует предложение, но год модели на странице не указан и ни одной живой странице не присваивается.

**SAVA.** Страница несёт два описания комплектации — структурированный блок (`ai-specs-accordion`) и собственную вкладку «Technical Specifications» продавца. Блок побеждает, различия сохраняются в `unknownFields` и `conflicting_sources`, ничего не сливается. У страниц с обоими блоками ошибки продавца видны: Gelaro S6 — адрес и тег `grx600`, название и детали `GRX610` (`FC-RX610-1`, `BL-RX610`): навеска берётся с детали страницы, не из адреса; Gelaro S8 — код Model говорит `RX810`, детали `RX820`. Год для S8 берётся из строки Model («2026 SAVA Gelaro S8»), а не из имени коллекции в адресе; у S6 его нет — `null`. Карточки с `US` в названии — отдельные предложения (другая комплектация склада), они не заменяют мировую. Другие домены марки (savabike.com, savabikes.com, sava-bikes.com) из сети разработки недоступны; savadeck.com — другая компания.

**SHULZ.** Подписи русские; разобраны «Рама», «Задний переключатель», «Манетки», «Система», «Каретка», «Задние звезды», «Рулевая» и др. Вес «13,1 кг» читается. Фреймсеты (`/catalog/framesets/…`) — не велосипеды (`not_complete_bike`). Бренд Strida, который продаёт SHULZ, — другая марка и не предлагается. Регистр и написание не важны: `Boys Don't Cry`, `Boys Don’t Cry`, `BoysDontCry`. Русское название модели («Вандерер») хранится как поле страницы; поиск идёт по латинскому названию каталога.

**TWITTER.** Сайт производителя www.twitterbike.com отдаёт пустые таблицы характеристик на всех проверенных моделях (25 страниц английской версии и две китайской) и по HTTPS отвечает сертификатом с чужим именем (проверку сертификата не отключаем); twittercycles.com из сети разработки недоступен. Спецификации публикует официальный магазин дистрибьютора twitterbikeusa.com (страница About: «official US distributor»), поэтому брендовый адаптер идёт через него и в `/v1/brands` помечен `kind: "distributor"`, а источник результата — `kind: "distributor"`. Одна страница — несколько сборок («System Configuration»): ячейки таблицы содержат строку на сборку с префиксом `<span>метка:</span>`; каждая сборка — отдельный кандидат `…?build=<метка>`, разбор оставляет только её строки (`None (1× setup)` — не педаль и не переключатель). Вставленная ссылка `?variant=` сопоставляется со сборкой по JSON-LD; ссылка без выбора берёт первую сборку и добавляет предупреждение `multiple_builds`. «CYCLONE 3rd EVO» как названия в магазине нет (проверено 2026-10-07): предлагаются ближайшие Cyclone 3rd (Pro, Advanced UCI, ET, 3K ED, R7120 Small) без домысливания; gravel-контроль — Gravel V3 (три сборки) и Gravel X. Рамы (`Spare Parts`) не предлагаются.

## Новый layout или поле

[extract.ts](../../services/bike-resolver/src/extract.ts) анализирует JSON-LD, инертные Next/application JSON, таблицы, definition lists, повторяющиеся блоки и семантические секции. [profiles.ts](../../services/bike-resolver/src/profiles.ts) — небольшие подсказки layout, не отдельный crawler. Классы дизайна не должны быть единственной опорой.

Стратегия выдаёт ограниченные raw fields с provenance; нормализация общая. Не смешивайте geometry, доставку, гарантию и маркетинг с компонентами. Не теряйте перед/зад у тормозов, втулок и покрышек. Неизвестные подписи и конфликтующие варианты сохраняются для review, а не заменяются фантазией.

При изменении семантики extraction/result поднимайте `EXTRACTOR_VERSION`/`RESULT_SCHEMA_VERSION`; при специфичном изменении адаптера — его version. Иначе прежние cache entries могут скрыть новый parser.

## Магазины и ручные ссылки

`ManualSources.resolve` принимает публичный URL с сохранением правил DNS/IP/redirect и blocklist. Ни credentials, ни произвольные request headers от клиента не разрешаются. Отсутствующий год — неопределённость; явно иной год/модель — конфликт, требующий подтверждения пользователем. Адрес зарегистрированного магазина читается его парсером независимо от флага поиска: флаг решает, участвует ли магазин в discovery.

Изображения берутся со страниц товара и выдаются как временные opaque IDs; приложение связывает выбор с пользователем, обрабатывает файлы и применяет квоты. Это не универсальный поиск картинок по интернету.

### Реестр магазинов

Магазин — объект `RetailStore` ([stores/types.ts](../../services/bike-resolver/src/stores/types.ts)), зарегистрированный в [stores/index.ts](../../services/bike-resolver/src/stores/index.ts) и в `storeSupport` ([settings.ts](../../services/bike-resolver/src/settings.ts)): точные домены (редирект за их пределы отклоняется), `owns`/`productKey` (страница товара и стабильный ID для объединения локализаций), `fetchUrl` (каноническая локаль), необязательный `discover` и `parse`. Нет `discover` — значит поиск по каталогу не подтверждён и `search: false`; адрес по-прежнему читается. **`parse` обязан отказывать рамам, деталям и аксессуарам** (`not_complete_bike`): у рамы часто три и больше «компонентов», пороги качества её не отличат. Признак — хлебные крошки JSON-LD или семейство товара в URL, но не название.

Discovery использует только публичные данные без ключей и скриптов: HTML-поиск магазина или его sitemap, разрешённый `robots.txt`. Встроенные в JavaScript ключи поисковых API (Algolia, Elastic) не извлекаются и не используются. Поисковая выдача (Bing RSS) — слабая подсказка адресов, не опора: оператор `site:` через неё не работает. Страница из подсказки всё равно скачивается и проверяется.

Добавьте новый магазин так: запишите минимум две фикстуры готовых велосипедов разных брендов и отрицательную (рама или аксессуар) утилитой `scripts/capture-fixture.ts`, реализуйте магазин, зарегистрируйте его с флагом по умолчанию и честным `limitation`, добавьте записи в `tests/fixtures/stores/manifest.json` с ожидаемым результатом и проверьте `tests/stores.test.ts`. Не вносите специальный случай одного велосипеда.

| Магазин   | Домены                               | Поиск                            | Состояние на 2026-10-07                                                                                                 |
| --------- | ------------------------------------ | -------------------------------- | ----------------------------------------------------------------------------------------------------------------------- |
| ВелоСклад | velosklad.ru                         | HTML-поиск каталога              | Работает; Scott Spark 950 из Popular Bikes 15                                                                           |
| Bikeinn   | www.tradeinn.com, только `/bikeinn/` | Публичная sitemap, не все товары | Работает; пять велосипедов и две отрицательные фикстуры. Встроенный поиск сайта (Elastic с ключом в JS) не используется |
| Alltricks | alltricks.fr, alltricks.com          | Нет                              | Разбор проверен на пяти страницах из Common Crawl (4 велосипеда, рама); сайт отвечает проверкой Cloudflare — выключен   |
| BIKE24    | www.bike24.com                       | Нет                              | Сайт отклоняет автоматические запросы (403 Akamai), страниц в Common Crawl нет: разбор не проверен — выключен           |

Фикстуры Alltricks получены не с живого сайта: его защита отвечает серверным запросам проверкой, обходить которую запрещено. Они сняты из публичного набора Common Crawl (запись WARC с файлом, смещением и SHA-256 хранится в манифесте, захват 2025-09). Это подтверждает разбор страниц, но не доступность сайта из сети сервера. Оператору, чьей сети страницы доступны: включите магазин в настройках, проверьте адрес в админском inspector, затем при необходимости реализуйте `discover` и снимите живые фикстуры утилитой.

Опциональный `web`-источник — Bing RSS: он подсказывает не более трёх адресов, каждый скачивается и проверяется (спецификация, идентичность), snippet не является комплектацией. Доступность endpoint не гарантируется; если нет пригодного результата, UI предлагает ручную ссылку/ввод.

### Снятие фикстур

`scripts/capture-fixture.ts` (`--store` для магазина или `--adapter` для производителя; `--json-products`/`--json-body` для ответов предиктивного поиска Shopify) записывает страницу в сокращённом виде и пополняет манифест: запрошенный и итоговый URL, время получения, SHA-256 исходного ответа и сокращённого файла, правило сокращения (селекторы, остаются `title`, canonical, `og:*` и JSON-LD; для карт сайта — буквальные фрагменты адреса, а не шаблон из аргумента) и происхождение — живой запрос через тот же safe HTTP-клиент либо запись Common Crawl (`--raw`/`--origin`). Не прикладывайте полные страницы, cookies и отчёты прогонов; тесты проверяют, что файл совпадает с записанным SHA-256.

## Проверки и приёмка

Нужны положительный fixture, соседний trim, неизвестный/иной год, маркетинговая ложная таблица, partial/unknown/conflict, charset и отказ сети. Тесты не обращаются к производителю. Live-проверка выполняется отдельно из релевантной сети и датируется; успешный разбор fixture не доказывает сегодняшнюю доступность источника.

Запуск из каталога сервиса: `npm run typecheck`, `npm test`, `npm run build`. Для пути preview→сохранение добавьте тест приложения. Запреты: обход challenge, отключение IP-проверок, исполнение HTML/JS и смешивание разных спецификаций ради полного списка.

## Popular Bikes 15

`tests/popular-bikes.test.ts` выполняет offline discovery → matching → acquisition → extraction → normalization для пяти MTB, пяти road и пяти gravel. `tests/fixtures/popular-bikes/manifest.json` содержит точные комплектации, URL, подтверждённый год, дату получения, SHA-256 исходного ответа и правила сокращения HTML. `requests.json` описывает реальные ответы каталогов и публичного API. Фикстуры сохраняют исходные узлы и значения; сетевые ответы в CI не требуются.

Выборка — известные серийные семейства, не рейтинг продаж. В ней Stumpjumper 15 Comp, Marlin 6 Gen 3, Spectral CF 7, Spark 950, Talon 1; Tarmac SL8 Comp, Madone SL 5 Gen 8, SuperSix EVO 1, Aeroad CF SLX 7 Di2, TCR Advanced 2; Diverge 4 Sport Carbon, Checkpoint ALR 5 Gen 3, Topstone 1, Revolt 1 и Grail CF 7. Точные годы, включая явно опубликованный Canyon 2027, берутся только из источника. Отсутствующий год и диапазон Trek 2026–2027 остаются `null`; такие кандидаты требуют выбора пользователем.

Trek использует инертные `product-card-item` каталога и публичные `/occ/v2/us/products/{code}/full` и `/specifications`. Код и URL товара проверяются до разбора; размерные варианты остаются в исходных полях и конфликтах. Specialized публикует в sitemap адреса `/en/`; адаптер проверяет их в US-локали. XML sitemap ограничен 24 MiB при одновременно подходящих URL и Content-Type (включая `octet-stream` только для каталогов media.specialized.com/sitemaps и wcpcdn.blob.core.windows.net/hybris/sitemap), остальные ответы, включая фото, — 8 MiB.

При недоступности официального источника допускается магазин: Scott Spark 950 в наборе проходит через ВелоСклад. Если Bing RSS недоступен или пуст, поиск использует публичный каталог магазина, затем проверяет саму карточку. Snippet не становится спецификацией, соседние годы/комплектации не принимаются автоматически. На дату получения фикстур Scott отдавал защитную страницу, а некоторые поисковые запросы возвращали пустые результаты или ошибки. Успешный offline-тест не гарантирует live-доступность.

Миграция 005 включает Trek и Cannondale для новых установок и нетронутых настроек (version 2 после миграции 003). Сохранённые оператором флаги адаптеров не перезаписываются: если они выключены на существующей установке, включите их в настройках Resolver после проверки.

## Reddit 10

Контрольный набор десяти велосипедов из r/gravelcycling (#361): Propain Terrel CF, Van Rysel GRVL AF Shimano GRX 2x12, Focus Atlas 6 LTD, Canyon Grail SLX AXS, Lauf Seigla Core Transmission, Giant Revolt 2, Canyon Grizl CF SLX 8, Canyon Grizl CF SL 6 2023, 3T Ultra Apex/Eagle 1x12 700c 2025, Ari Shafer CUES 1x11 2026. Обсуждение — источник запроса человека, а не эталон заводской комплектации; неполные названия и неизвестные годы сохранены намеренно. `tests/fixtures/reddit10/manifest.json` фиксирует для каждого запроса: текст, ссылку на пост, нормализацию в поля мастера, выбранный вариант, вставленную страницу, подтверждение года и trim, ожидаемые компоненты и список прочитанных страниц; `pages.json` — происхождение каждой записи (дата, SHA-256 всей страницы, правило сокращения). Дата поста — `null` с причиной: reddit.com отвечает safe-клиенту 403, а дата issue не подменяет дату поста и не становится модельным годом.

`tests/reddit10.test.ts` проигрывает по записям весь путь обнаружение → выбор → разбор → нормализация через HTTP-интерфейс сервиса, включая NDJSON и брошенный посреди обхода запрос, и падает, если путь просит страницу, которой нет в записях. Исход каждого велосипеда относится к одному из четырёх классов: `identified` (предложен, выбран, разобран, название страницы совпало с запросом) — единственный, который считается подтверждённой комплектацией; `parsed_unconfirmed` (разобран, но название или trim страницы отличаются: `identity_mismatch`); `alternatives_only` (предложены варианты, ни один не запрошенный велосипед, ничего не читается и не импортируется); `not_found`. Выдача `ambiguous` без последующего выбора и разбора успехом не считается. Через приложение тот же путь проходит `tests/resolver-reddit10-http.js`: выбор по id, preview владельца, импорт со своим годом и происхождением, отдельные варианты не смешиваются.

## Фото компонентов

Commons ищется максимум тремя запросами: категория + бренд + модель, бренд + модель, затем отдельные слова модели. Модель сохраняется во всех вариантах; поиск только по бренду не выполняется. Пустые результаты кешируются, ошибки API и ограничения частоты не запускают следующий запрос. Для больших оригиналов запрашивается копия шириной до 1600 px; проверяются её домен, формат и размеры, а загрузка по-прежнему ограничена 8 MiB.

В результат попадают только поддерживаемые свободные лицензии с авторством. Пустая выдача означает отсутствие подходящих результатов с нужной лицензией и разрешением, а не доказанное отсутствие любых фото. В диалоге есть ссылка на ручное уточнение запроса в Commons; импорт по-прежнему требует явного выбора и подтверждения.

Все запросы проходят существующий safe HTTP. Индексы ограничены 50 000 записей, четырьмя ключами и TTL 6 часов; HTML документов производителей использует существующий bounded cache. Для магазинов сохраняется общий бюджет 12 страниц, максимум 4 на магазин: при шести searchable источниках — по 2, при восьми — как минимум по 1. Для Trial-Sport к discovery/page budget добавляются 10 секунд на обязательную очередь; общий deadline запроса 90 секунд и отмена остаются прежними.
