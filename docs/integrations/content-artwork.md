# Изображения контента и медиатека

[Оглавление](../README.md)

## Назначения

Админка → Дизайн → Главная страница управляет картинкой рядом с заголовком hero. «Изображения и брендинг» содержит favicon, фотографии по умолчанию для трёх типов велосипеда, демонстрационный велосипед и две иллюстрации «О проекте». Графика рекордов и достижений настраивается в разделе механик.

`lib/design-graphics.js` описывает слоты контента. `lib/site-assets.js` собирает используемые UUID только из разрешённых полей и настроек наград. Иконки кнопок, меню и вкладок встроены в приложение и не являются загружаемыми ресурсами.

## Жизненный цикл

Загрузка в медиатеку не публикует изображение автоматически. Выберите файл в слоте и сохраните настройки. Сброс назначения возвращает встроенное пустое состояние или скрывает необязательную иллюстрацию. Файлы получают серверные имена; фотографии пользователей хранятся отдельно от `site_assets`.

Настройки сохраняются с версией; конфликт требует перечитать данные. Очистка принимает явный список UUID, проверяет назначения после блокировки строк и удаляет только неиспользуемые файлы. Клиент защищает также текущий черновик. Опубликованный файл нельзя удалить, просто сняв назначение в несохранённом черновике.

Загруженные раньше, но больше не используемые изображения остаются в медиатеке до явной очистки. Автоматическая миграция не удаляет файлы пользователя.

## Проверки

`tests/admin-design.test.js` проверяет разрешённые слоты, строгую схему settings и безопасную очистку. `tests/e2e/garage-polish.spec.js` проверяет загрузку, назначение, защиту используемого файла и отклонение удалённых настроек. `community-design.spec.js` проверяет замену и сброс hero-картинки.
