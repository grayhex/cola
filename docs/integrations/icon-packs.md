# Иконки, ZIP-наборы и графика

[Оглавление](../README.md)

## Назначение и модель

[icon-pack.js](../../lib/icon-pack.js) содержит реестр 64 семантических слотов, групп, fallback и legacy-совместимости. [SiteIcon](../../app/ui/icons.jsx) использует настройки сайта, не меняя смысл действия. Общая UI-иконка и иллюстрация конкретной награды — разные назначения; для последних см. [достижения](../modules/gamification.md).

Связи UI хранятся в `settings.uiIcons`, файлы — в `site_assets`/photos volume. Приоритет: явный semantic slot → совместимый старый специальный slot → старое Lucide-назначение → встроенный значок. `null` в semantic slot означает явный возврат к встроенному варианту. Импорт не создаёт новую функцию только потому, что в наборе есть её иконка.

## Работа администратора

Админка → Дизайн → Оформление → «Единый набор ColaBike · 64 иконки». Выберите ZIP, проверьте пары текущая/новая, нужные слоты и режим «заменить выбранные» либо «только заполнить пустые». Предпросмотр не записывает assets. Подтверждение подготавливает ресурсы и меняет локальный draft; публикация — штатным сохранением настроек с version check.

У слота есть отдельная загрузка, выбор из медиатеки и сброс. Частичный набор не очищает отсутствующие назначения. Баннер, фон, логотип, favicon, фото и персональные награды этим ZIP не заменяются.

## Формат и защита

Используются masters `png/<name>.png`, допускается внешний каталог архива. Известные PNG/WebP с теми же именами распознаются; `png/` приоритетнее корневой копии, равноприоритетный дубль — ошибка. SVG, sprite sheets, previews, README и вспомогательные размеры пропускаются и не исполняются.

Одиночная иконка — статический квадратный PNG/WebP 16–512 px до 2 MiB; рекомендуемый master 64×64. После декодирования хранится lossless WebP без изменения размера, с прозрачностью. Это отдельный путь, не обычный lossy photo converter.

`POST /api/admin/icon-pack?action=preview|stage|single` проверяет admin, Origin и rate limit до тела. ZIP ограничен 10 MiB, 1024 entries и 32 MiB суммарного заявленного распакованного размера; selected file — 2 MiB. Поддерживаются STORE/DEFLATE без ZIP64/шифрования/многотомности/ссылок. Проверяются paths, headers, перекрытия, CRC, заявленные/фактические размеры и лимит inflate.

Архивный путь не используется как путь записи. Ресурсы получают UUID, ошибка подготовки очищает частичные записи. При отказе от сохранения подготовленные assets остаются в медиатеке; их можно удалить, пока они не используются. Удаление назначенной графики блокируется.

## Разработка и проверки

Используйте `SiteIcon` по смыслу, не перегружайте одну Lucide-иконку несвязанными назначениями. Ограничивайте область рендера: загруженный `<img>` не должен попадать под CSS фотографии. `aria-label` принадлежит интерактивной кнопке/ссылке; декоративная картинка не заменяет её доступное имя.

```bash
node --test tests/icon-pack.test.js tests/icon-pack-images.test.js
```

Проверьте полный/частичный import, дубль, повреждённый ZIP, oversized/decompression, отсутствие роли, version conflict, single replace/reset, сохранение после reload и неизменность баннеров. Схему импорта и назначение нового слота обновляйте вместе с этой главой.
