# Публичные адреса и превью ссылок

Публичные страницы открываются по адресам `/b/<slug>-<id>` (велосипед), `/j/<slug>-<id>` (запись журнала), `/r/<slug>-<id>` (покатушка), `/market/<slug>-<id>` (объявление) и `/@<username>` (профиль). `<id>` — неизменяемый восьмисимвольный идентификатор из цифр и латиницы без `i`, `l`, `o`, `u`. Его выделяет триггер при создании записи, и он не переиспользуется даже после удаления объекта. `slug` строится из названия (латиница, цифры, кириллица) и меняется при переименовании. Объект ищется по `<id>`, поэтому адрес со старым slug перенаправляет на актуальный.

Старые ссылки `/b/<uuid>`, `/j/<uuid>`, `/r/<uuid>`, `/market/<uuid>` и `/u/<username>` отвечают постоянным перенаправлением 308 на канонический адрес с сохранением query-параметров. Внутренние UUID и поля API `share_id`/`shareId` не меняются: клиент и API по-прежнему работают с ними. Ответы API, где встречаются такие поля, дополняются `public_id` и `slug` одним пакетным запросом и только тогда, когда зритель может прочитать объект. Ссылки `href` вида `/b/<uuid>` и `/u/<username>` переписываются на канонические. Маршруты `/api/{journal,market,rides}/public/<ссылка>`, `/api/rides/owner/<ссылка>` и `/api/shared/<ссылка>` принимают и UUID, и `<slug>-<id>`.

Приватный объект гость видит как страницу «недоступно» с общими метаданными `noindex` и без превью. Владелец, а для покатушки и приглашённые, перенаправляются на канонический адрес. Приватный родитель (велосипед записи или покатушки) скрывает и дочерний объект.

## Метаданные и картинка превью

Страницы отдают Open Graph и Twitter Card, `canonical` и описание без Markdown и HTML. Абсолютные адреса строятся от `PUBLIC_SITE_URL`, а без неё — от `APP_ORIGIN`. Заголовок `Host` не используется. В production допустим только публичный HTTPS-адрес, иначе приложение не стартует ([развёртывание](../operations/deployment.md)). `htmlLimitedBots: /.*/` в `next.config.mjs` выводит теги в начальный `<head>` для любых клиентов, чтобы превью видели все мессенджеры, а не только известные Next боты.

Картинка — `/api/social-preview/<kind>/<id>/image`: JPEG до 1200×630 без увеличения. Источник:

- для велосипеда — обложка или первая фотография;
- для записи — её первое фото, а если его нет, фото велосипеда;
- для покатушки — фото велосипеда;
- для объявления — первое фото;
- для профиля — аватар.

Если фото нет, рисуется заглушка ColaBike. Публичность проверяется при каждом запросе, ответ помечен `private, no-store`.

## Данные

Миграция [023_public_urls.sql](../../db/023_public_urls.sql):

- `public_url_keys` — выделенные идентификаторы;
- `public_url_aliases` — старые UUID-ссылки, которые нельзя переназначить другому объекту;
- функция `allocate_public_id` — выбор идентификатора без коллизий;
- триггер `zz_public_url_identity` на `bikes`, `journal_entries`, `rides`, `market_listings` и `users`;
- представление `public_entity_links` — правила видимости ссылок.

Представление не заменяет авторизацию: после разрешения ссылки обычные обработчики API проверяют доступ как раньше.

Код: [public-urls.js](../../lib/public-urls.js) (форматы и разбор ссылок), [public-link-data.js](../../lib/public-link-data.js) (разрешение и дополнение ответов), [social-page.js](../../lib/social-page.js) (канонические страницы), [social-preview.js](../../lib/social-preview.js) и [social-preview-image.js](../../lib/social-preview-image.js) (превью). Next передаёт динамические сегменты в percent-кодировке, поэтому `routeParam` декодирует их перед сравнением: иначе кириллический slug перенаправлял бы сам на себя.
