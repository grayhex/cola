# Рынок

Раздел `/market`: велосипеды, комплектующие и аксессуары. Объявление содержит название, описание, состояние, цену/валюту, город, контакт для вошедших пользователей и до восьми фотографий. Автор может редактировать, сохранить черновик, опубликовать, снять с публикации, отметить проданным или удалить объявление. Оплаты и переписки внутри сайта нет.

Опубликованные объявления входят в события и блок «Что нового» на главной; объявления людей из подписок также входят в `/feed`. Черновики видит только владелец. Проданные объявления доступны по прямой ссылке со статусом, но исключены из лент. Блокировка автора закрывает все его объявления и фотографии.

Контакт продавца не входит в списки, ленты и карточку: DTO сообщает только `hasContact`, сам контакт видит владелец. Вошедший пользователь открывает его кнопкой «Показать контакт» — `GET /api/market/public/:share/contact`, не больше 20 запросов за 15 минут на человека; гость видит предложение войти. Контакт отдаётся только для активного объявления (владельцу — для любого своего).

Фильтры в URL и запросе: `q`, `category`, `type`, `condition`, `price_min`/`price_max` (целые рубли, границы включительно; объявления без цены при заданной границе не попадают), `city` (подстрока поля «Город») и `sort=new|price_asc|price_desc`. Неверные значения API отклоняет с 400. Одно и то же условие `WHERE` считает `total` и выбирает страницу. Сортировка «Сначала новые» идёт по дате публикации и использует индекс `market_publication`; сортировка по цене и фильтр города пока обходятся без отдельного индекса — активных объявлений немного, индекс по цене стоит добавить при росте рынка. Карточки показывают «Опубликовано сегодня / вчера / N дней назад» по календарным дням пользователя.

`/api/market` — список и создание; `/public/:share` — карточка; `/public/:share/contact` — контакт; `/:id` — изменение/удаление; `/:id/photos` — загрузка; `/media/:id` — чтение/удаление фото. Все изменения требуют сессии и проверки Origin. Поля проверяются схемой; контакты и описания выводятся как текст. JPEG/PNG/WebP перекодируются в WebP, исходники не публикуются. Максимум 100 объявлений, 8 фото в объявлении, 240 фото рынка на автора; учитывается общий лимит места вместе с велосипедами, журналом и аватаром. Удалённые и осиротевшие фото убирает `scripts/cleanup-rides.js`.

Миграция: `017_rides_market`. Таблицы `market_listings`, `market_photos`, `market_photo_gc`.
