# Поиск фотографий компонентов (#147)

На странице модели кнопка «Найти фото» ищет **только в Wikimedia Commons**.
Это ограниченная коллекция, а не поиск по всем магазинам/производителям:
у многих конкретных моделей фотографий нет. Поиск использует категорию,
бренд и имя из серверной записи модели; для основных категорий есть английские
поисковые термины. Пользователь выбирает до трёх кандидатов, проверяет модель,
источник и лицензию и явно подтверждает публикацию. Автоматической публикации нет.

## Источник и конфигурация

- [MediaWiki Action API / Search](https://www.mediawiki.org/wiki/API:Search),
  [Imageinfo](https://www.mediawiki.org/wiki/API:Imageinfo):
  `https://commons.wikimedia.org/w/api.php`, только чтение, без API-ключа.
- [Правила повторного использования](https://commons.wikimedia.org/wiki/Commons:Reusing_content_outside_Wikimedia):
  лицензия и авторство относятся к конкретному файлу. Wikimedia не гарантирует
  корректность этих сведений; пользователь проверяет страницу источника.
  Поддержаны CC BY/CC BY-SA 2.0, 2.5, 3.0, 4.0 и CC0 1.0 с полными метаданными.
  Остальные лицензии и неполные сведения исключаются. После преобразования
  в WebP сохраняются и показываются автор, credit, источник, лицензия и описание
  технических изменений; автор загрузки на ColaBike обозначается «Добавил».
- [Лимиты Wikimedia](https://www.mediawiki.org/wiki/Wikimedia_APIs/Rate_limits)
  на дату проверки 27.09.2026: 200 запросов/мин для клиента с корректным
  User-Agent; правила могут меняться. Отдельный клиент использует контактный
  User-Agent, последовательные запросы к каждому хосту, действующий интервал
  Resolver (не менее 500 мс), не повторяет ошибочные запросы автоматически и
  выдерживает Retry-After при 429/503 (минимум 5 секунд).
- Внешняя сеть доступна только Resolver. Используются существующие
  `BIKE_RESOLVER_URL` и настройки администратора `enabled` / `photoSearch`;
  новых секретов и CSP-разрешений нет. Выключение поиска фотографий в Resolver
  выключает также этот источник. Недоступность показывает понятную ошибку;
  ручные загрузки продолжают работать по прежней матрице прав.
- На пользователя: 15 поисков и 90 предпросмотров за 15 минут; импорт входит
  в существующий лимит загрузок. Кеш поиска — 15 минут, максимум 40 запросов;
  память Resolver хранит максимум 500 временных кандидатов, без копий файлов.

27.09.2026 проверка API из среды разработки через доступный HTTP-прокси получила
200 и JSON с исходными URL и лицензиями для запросов Brooks/Schwalbe/Shimano.
Подходящие результаты не гарантируются: в проверенной выдаче Brooks C17 их не было.
Полный запрос `saddle / Brooks / B17` дал шесть допустимых кандидатов после фильтров,
включая B17 Titanium. Один реальный JPEG успешно скачан через HTTP-прокси и
обработан общей медиасистемой в WebP 2400 × 1800 без EXIF. Это проверка ответа,
файла и обработки, а не сквозной production-smoke защищённого сетевого клиента.
Openverse вернул 403 и не выбран. Прямой запрос защищённого Node-клиента из этой
среды завершился `dns_failed`; это ограничение проверки, а не подтверждение
недоступности Wikimedia с VPS. Production live-smoke требуется отдельно.

## Права, сохранение и ограничения

Поиск доступен вошедшему незаблокированному пользователю при полностью пустой
галерее, администратору — также при наличии фото. Владелец велосипеда с компонентом
для поиска не требуется. Скрытые фото, фото заблокированных авторов и фотографии
объединённых моделей учитываются при проверке пустоты. Публикация требует
подтверждённой почты по общей политике сайта.

Кандидаты привязаны к пользователю и модели в БД и живут 15 минут; перезапуск
Resolver или новый поиск может сделать прежний выбор недоступным. Клиент передаёт
только идентификаторы и подтверждение, произвольные URL импортировать нельзя.
Перед записью всей подборки в одной транзакции повторяются проверки актуального
пользователя, роли, пустоты галереи, кандидатов и общих квот. Используются те же
блокировки users → catalog, что у ручных загрузок и объединений; успешный импорт
погашает кандидатов. При отказе не остаётся частично опубликованной подборки.

Загрузки ограничены хостами Commons/upload/thumb Wikimedia и HTTPS. На каждом
редиректе и DNS-разрешении применяется существующая SSRF-защита Resolver с
закреплением проверенного публичного IP за соединением. До 4 редиректов, 15 секунд
на операцию; файл до 8 МиБ, JPEG/PNG/WebP, минимум 600 × 400 px, максимум 40 Мп.
Байты повторно проверяет Sharp: локальный WebP до 2400 px с удалением EXIF.
SVG и неподходящие файлы отклоняются. Галерея использует `/api/components/media/`
и общие варианты размеров, удаление/модерацию/очистку #146; постоянного hotlink нет.

Миграция `032_component_photo_search` добавляет nullable `source` к существующим
фотографиям и временную таблицу кандидатов. Прежние фотографии и подписи сохраняются.
Выгрузка аккаунта включает атрибуцию; удаление аккаунта удаляет его кандидатов.

## Проверки и приёмка

Автоматические проверки не требуют интернета: синтетический ответ Commons в
Resolver, unit-проверки URL/MIME/размеров/лицензий/Retry-After, тесты БД на права,
токены, атомарность и повторный импорт. HTTP проверяет гонку двух пользователей
на первой загрузке (PostgreSQL в CI), Origin, пустую выдачу и ошибку источника.
Браузеры проверяют предпросмотр, подтверждение, атрибуцию, обе темы и ширину от 320 px.

После приёмки PR и разрешённой владельцем выкладки:

1. Открыть пустую модель обычным подтверждённым пользователем без её установки.
   Проверить реальный ответ Commons; при отсутствии фото результат должен быть
   пустым, при ошибке сети — сообщением о недоступности.
2. Для модели с подходящими кандидатами проверить превью, открыть источник и
   лицензию, выбрать несколько фото и подтвердить публикацию. Проверить локальное
   сохранение, авторство и отсутствие кнопки поиска для обычного пользователя
   после заполнения галереи. Администратор может добавить ещё.
3. Проверить выключенный поиск в настройках Resolver, ручную загрузку владельцем
   компонента, телефон и обе темы. Новые ключи/аккаунты провайдера не нужны.

Issue #147 и epic #132 закрываются после приёмки владельцем, с отдельной отметкой
о live-проверке. Fixture-тесты не подтверждают сетевую доступность или полноту
реальной коллекции.
