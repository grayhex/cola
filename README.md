# ColaBike

Личный велогараж: фотографии, актуальная комплектация, аксессуары и публичная карточка по ссылке. Next.js + PostgreSQL. Интерфейс на русском.

## Локальный запуск через Docker

Нужен Docker Desktop / Docker Engine с Compose.

```sh
git clone https://github.com/grayhex/cola.git
cd cola
docker compose up --build -d
```

Откройте http://localhost:3000 и создайте аккаунт. Демо на главной доступно без регистрации, его сборка иллюстративная и не заявлена как заводская комплектация. У новых пользователей пустой личный гараж.

Миграции применяются автоматически до запуска приложения. PostgreSQL и фотографии сохраняются в именованных volumes `database` и `photos`. Обычный `docker compose down` сохраняет данные. **Не используйте `down -v`, если данные нужны.** База не выставляется наружу.

```sh
docker compose logs -f app
docker compose down
```

## Возможности

- Регистрация email/пароль (от 10 символов), вход и выход; пароли хешируются scrypt, случайные сессии хранятся в БД в виде SHA-256, cookie HttpOnly / SameSite.
- Несколько велосипедов: имя, марка, модель, год, категория, размер, вес, цвет, описание.
- До 12 фотографий на велосипед, JPEG/PNG/WebP до 10 МБ; выбор обложки и удаление. Изображения декодируются, уменьшаются до 2400 px, перекодируются в WebP без EXIF.
- Отдельные вкладки комплектации и аксессуаров, добавление/изменение/удаление деталей, необязательная цена в рублях. Хранится только актуальное состояние.
- Локальный справочник марок и моделей gravel/MTB/road, производителей, серий и моделей компонентов; ручной ввод разрешён. Источник данных — `lib/catalog.js`, база не подставляет заводские сборки и не проверяет совместимость.
- Приватность по умолчанию. Включаемая ссылка `/b/<uuid>` показывает фото и детали, но не цены и почту. Закрытие доступа меняет токен; старые ссылки не оживают при повторной публикации. Авторизация проверяется и на чтении фотографий, кэширование приватных ответов отключено.
- Ограничение попыток входа и регистрации в PostgreSQL, проверка Origin для изменений, параметризованные SQL-запросы и серверная валидация.

## Настройка

При стандартном локальном запуске `.env` не обязателен. Для изменения настроек скопируйте `.env.example` в `.env`. Если открываете с другого устройства, укажите точный `APP_ORIGIN`, например `http://192.168.1.20:3000`. Не добавляйте завершающий `/`.

Для хостинга: установите надёжный `POSTGRES_PASSWORD` до первого создания БД, внешний HTTPS origin в `APP_ORIGIN` и `COOKIE_SECURE=true`; используйте reverse proxy с HTTPS и ограничением размера тела запроса 11 МБ. Пароль должен быть URL-safe либо отдельно задайте корректно экранированный `DATABASE_URL` в Compose. Смена переменной пароля не меняет пароль уже созданного PostgreSQL volume.

Перед публичным запуском потребуется почтовый провайдер для подтверждения адресов и восстановления паролей — эти сценарии в MVP пока не реализованы. Нет OAuth. Сессии истекают через 30 дней. Регистрация не создаёт демонстрационные учётные записи. Справочник намеренно ограниченный, расширяется в исходном файле.

Фотографии пользователей лежат только в локальном volume. Для резервной копии сохраняйте PostgreSQL (`pg_dump`) и volume фотографий вместе. Переход на S3 можно выполнить отдельно при выборе хостинга.

## Разработка и проверки

Node.js 22+, pnpm 11.19.0. Для запуска без Docker нужна работающая PostgreSQL и переменные окружения из `.env.example` (Next.js читает `.env.local`; CLI миграции запускайте с `node --env-file=.env.local scripts/migrate.js`).

```sh
pnpm install --frozen-lockfile
pnpm test
pnpm build
pnpm dev
```

Тесты используют настоящий PostgreSQL-движок PGlite в памяти: проверяют изоляцию владельцев, скрытие цен, отзыв ссылки, каскадное удаление, валидацию и пароли. Это не заменяет smoke-test Docker на целевой машине.

## Демо и источники справочника

Изображение демо загружается с сайта [Canyon](https://www.canyon.com/en-si/outlet-bikes/gravel-bikes/grizl-al-7-raw/50051247.html), с указанием источника в карточке; для него нужен интернет. Пользовательские фотографии работают локально. Внешнее фото используется только как визуальная демонстрация, права остаются у Canyon. Перед коммерческой публикацией замените его собственной фотографией или лицензированным изображением.

Названия компонентов сверены с [Shimano](https://bike.shimano.com/en-UK/bike-selector.html) и [Brooks](https://www.brooksengland.com/pages/faq); справочник содержит также общеупотребимые наименования других производителей, не является каталогом актуального наличия и не гарантирует совместимость. Шрифт Manrope загружается с Google Fonts; при отсутствии сети используется Arial.
